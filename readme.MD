# 🏴‍☠️ OverTheWire Wargames - Writeups & Walkthroughs

Selamat datang di repository saya! Repository ini berisi dokumentasi lengkap, *step-by-step*, catatan belajar, dan *writeup* dari berbagai *wargame* yang disediakan oleh [OverTheWire](https://overthewire.org/wargames/).

Wargames dari OverTheWire adalah platform latihan yang sangat fantastis untuk mempelajari dan mempraktikkan konsep-konsep *Cybersecurity*, mulai dari dasar-dasar *command-line* Linux, keamanan web, kriptografi, hingga *binary exploitation*.

## 📂 Daftar Wargames (Kategori)
Repository ini disusun berdasarkan nama *wargame*. Klik pada masing-masing kategori untuk melihat *writeup* detail di setiap levelnya:

### 🐧 Dasar-dasar Linux & Server
*   [**Bandit**](./Bandit/) - Wargame wajib untuk pemula. Fokus pada perintah dasar Linux, manipulasi teks, *permissions*, dan pengenalan *command-line interface* (CLI).
*   [**Leviathan**](./Leviathan/) - Melanjutkan pemahaman command-line dengan sedikit sentuhan pemahaman sistem.

### 🌐 Keamanan Web (Web Security)
*   [**Natas**](./Natas/) - Wargame yang berfokus pada keamanan aplikasi web. Mempelajari kerentanan *server-side*, injeksi, *cross-site scripting*, dan *session management*.

### 🔐 Kriptografi (Cryptography)
*   [**Krypton**](./Krypton/) - Wargame tentang kriptografi klasik dan dasar. Memecahkan berbagai sandi dan kode (*ciphers*).

### 🐛 Eksploitasi Biner & Reverse Engineering
*   [**Narnia**](./Narnia/) - Pengantar ke eksploitasi memori (*memory corruption*), *buffer overflows*, dan cara kerja *stack*.
*   [**Behemoth**](./Behemoth/) - Eksploitasi biner tingkat lanjut.
*   [**Maze**](./Maze/) - Latihan eksploitasi biner dengan tingkat kesulitan yang lebih tinggi.

*(Kategori dan link di atas akan terus di-update seiring dengan level dan wargame baru yang saya selesaikan)*

## 🛠️ Tools & Pengetahuan yang Digunakan
Sepanjang penyelesaian wargame ini, saya menggunakan dan mempelajari berbagai *tools* standar industri, antara lain:
*   **Linux Core Utilities:** `bash`, `grep`, `awk`, `sed`, `find`, `tar`
*   **Networking:** `ssh`, `netcat (nc)`, `nmap`, `openssl`, `Wireshark`
*   **Web Testing:** `Burp Suite`, `cURL`, Developer Tools
*   **Exploitation & Debugging:** `gdb`, `pwntools`, `radare2`, `Python`
*   **Cryptography:** `base64`, `CyberChef`, custom script dekripsi
